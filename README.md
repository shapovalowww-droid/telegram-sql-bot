# Telegram SQL Bot

Telegram-бот для системного изучения SQL: уроки, квизы, практика на реальной базе и подборка SQL-новостей. Рос как личный инструмент при освоении SQL для задач анализа данных в безопасности и фрод-аналитике.

## Возможности

- **Уроки** — структурированные материалы от SELECT/WHERE до JOIN, агрегаций и оконных функций
- **Квиз** — проверка теории с разбором ошибок
- **Практика** — выполнение SQL-запросов в учебной БД прямо из бота
- **Справочник** — быстрые шпаргалки по синтаксису и операторам
- **SQL-новости** — автоматическая подборка из открытых источников с настраиваемой периодичностью

## Стек

- Python 3
- aiogram (Telegram Bot API)
- SQLite (локальная БД для уроков и пользовательского прогресса)
- python-dotenv (конфигурация через `.env`)

## Структура

```
bot.py           — точка входа
config.py        — настройки из переменных окружения
handlers/        — обработчики команд и колбэков
keyboards/       — inline-клавиатуры
services/        — бизнес-логика: уроки, квизы, новости, БД
data/            — учебные материалы и контент
db/              — миграции и работа с SQLite
```

## Запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать .env с токеном бота
echo "BOT_TOKEN=ваш_токен_от_BotFather" > .env

# 3. Запустить
python bot.py
```

Опциональные переменные окружения:
- `NEWS_INTERVAL_HOURS` — частота обновления новостей (по умолчанию 4)
- `NEWS_PER_SOURCE` — количество новостей на источник (по умолчанию 2)
- `DB_PATH` — путь к файлу БД (по умолчанию `db/sql_bot.db`)

## Зачем

Pet-проект совмещает две задачи: освоение SQL для аналитики данных и разработку учебного формата, который может быть полезен другим специалистам, переходящим в data-направление из смежных областей.
