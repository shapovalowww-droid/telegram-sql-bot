# Карьерный ИИ-ассистент (Telegram + Claude)

ИИ-агент в Telegram, который помогает найти работу: подбирает вакансии на **hh.ru**,
разбирает конкретную вакансию под профиль пользователя и проводит тренировку
собеседования. Построен на **Claude** (Anthropic API) с tool use (function calling).

## Возможности

- **Поиск вакансий** — агент сам формирует фильтры из запроса на естественном языке
  и ищет через открытый API hh.ru (`search_vacancies`).
- **Разбор вакансии** — по тексту или ссылке hh.ru оценивает соответствие профилю,
  сильные стороны, пробелы и что подчеркнуть в отклике (`get_vacancy_details`).
- **Подготовка к собесам** — mock-интервью: вопрос → ответ → конструктивный фидбэк.
- **Трекер откликов** — сохранение вакансий со статусами (сохранено / отправлено /
  собеседование / оффер / отказ); управляется в диалоге (`save_application`,
  `update_application`, `list_applications`) и кнопкой «Мои отклики».
- **Профиль пользователя** — хранится и подставляется в системный промпт, чтобы
  советы были персональными.
- **Память диалога** — мультитёрн с сохранением истории в SQLite.

## Стек и ключевые решения

- Python 3.10+
- [`python-telegram-bot`](https://docs.python-telegram-bot.org/) (async) — Telegram
- [`anthropic`](https://github.com/anthropics/anthropic-sdk-python) — Claude API
  - модель `claude-opus-4-8`, `thinking: adaptive`, `effort: medium`
  - ручной агентный цикл (tool use), prompt caching системного промпта
- `aiohttp` — асинхронный клиент hh.ru
- `aiosqlite` — профили, режим и история диалога

## Структура

```
bot.py                      — точка входа, регистрация хендлеров
config.py                   — настройки из .env
agent/
  claude_agent.py           — агентный цикл Claude (tool use + кеширование)
  tools.py                  — определения инструментов и их исполнение
  prompts.py                — системный промпт (база + профиль + режим)
services/
  hh_api.py                 — асинхронный клиент API hh.ru
storage/
  db.py                     — SQLite: профиль, режим, история
handlers/
  telegram_handlers.py      — команды, кнопки, диалог
keyboards/
  menus.py                  — клавиатура меню
```

## Запуск

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Конфигурация
cp .env.example .env
#   заполни BOT_TOKEN (от @BotFather) и ANTHROPIC_API_KEY

# 3. Старт
python bot.py
```

## Команды

- `/start` — приветствие и клавиатура меню
- `/profile <текст>` — задать/обновить профиль (без аргумента — показать текущий)
- `/reset` — начать новый диалог (очистить историю)

Кнопки меню: 🔍 Поиск вакансий · 📋 Разбор вакансии · 🎤 Собеседование · 📁 Мои отклики · 👤 Профиль · ♻️ Новый диалог

## Заметки

- API hh.ru для поиска вакансий не требует авторизации, нужен лишь `User-Agent`
  (задаётся в `config.py` / `.env`).
- Системный промпт кешируется (`cache_control: ephemeral`) — это основная экономия
  токенов при мультитёрн-диалоге.
- История обрезается до `MAX_HISTORY_MESSAGES` с сохранением целостности пар
  `tool_use`/`tool_result`.
